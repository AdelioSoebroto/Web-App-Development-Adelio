# Web Application Development: weekly exercises

My exercises for the Web Application Development course (2023). Each folder is one week of the course,
from plain HTML and CSS up to a PHP and Laravel app.

| Folder | What it covers |
|---|---|
| `Latihan Week 2` | Basic HTML pages |
| `Latihan Week 3` | HTML with CSS styling |
| `Latihan Week 5` | More page layout exercises |
| `Latihan Week 7` | A PHP + MySQL CRUD app: list, add, edit and delete records (`olen_store.sql` is the database) |
| `Latihan Week 13` | A Laravel application skeleton |

This is coursework kept as a learning record, not a maintained project.
